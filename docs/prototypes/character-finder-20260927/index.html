NAI · 캐릭터 찾기 시안 (2026-09-27)

Prombot 웹사이트를 열지 않고 앱 안에서 시리즈별로 썸네일을 보며 캐릭터를 고르고, 별표로 캐릭터 도감에 넣고, 눌러서 지금 캐릭터에 넣는 화면입니다. Galaxy Tab S11 세로(800×1280) 정적 목업이며 배치 A(대상별 3구역)를 기준으로 합니다. 썸네일은 CSS 그림(실제 Prombot 썸네일처럼 밝은 회색 배경의 전신 그림)이고, 캐릭터·시리즈 이름과 전체 수는 Prombot 목록(2026-09-12, 19,193명 · 1,896개 시리즈)에서 가져왔지만 도감 수, 신규 수, 받기 진행률은 예시 값입니다. 노란 메모는 설명용입니다.

정한 것

들어가는 곳캐릭터 탭 보드 도구줄의 첫 버튼 캐릭터 도감 → 캐릭터 찾기. 입력 중 키보드 위 줄도 같은 이름. 캐릭터 메뉴의 Prombot 항목은 없앱니다.
찾기와 도감은 한 시트, 탭 두 개[찾기 | 내 도감]. 찾기에서 ★ 누르면 도감에 들어가고, 두 탭 모두 같은 타일·같은 넣기 화면을 씁니다.
썸네일 3:4, 잘라내지 않음Prombot 썸네일은 폭 400–448px, 비율 0.6–0.96의 전신 그림이라 2:3이나 정사각형으로 자르면 머리나 발이 잘립니다. 3:4 칸에 통째로 넣고 남는 곳은 같은 밝은 회색으로 채웁니다.
누르면 넣기 패널타일을 누르면 아래에서 패널이 올라와 외형·의상 태그를 보여 주고, 이름만 / 이름+외형 / 이름+외형+의상 중 고르고 넣습니다. 고른 방식은 다음에도 기억합니다.
🎲 랜덤 범위는 도감 탭에서도감 전체 또는 고른 시리즈만. 지금은 Prombot에서 가져온 북마크만 뽑히지만, 바꾼 뒤에는 도감에 넣은 캐릭터 모두가 대상입니다.

A3넣기 패널

캐릭터를 누르면 아래에서 패널이 올라옵니다. Prombot 목록의 외형(features)·의상(attire) 태그를 칩으로 보여 주고, 무엇을 넣을지 세 가지 중에 고릅니다. 칩을 눌러 한 개씩 뺄 수도 있습니다. 아래 미리보기가 실제로 들어갈 글자입니다.

  • 이름만: 지금 도감에서 고를 때와 같음. 이름 태그만 바꿉니다.
  • +외형 / +의상: 이름 뒤에 붙입니다. 전에 찾기로 넣은 외형·의상 태그는 새 것으로 바뀌고, 사용자가 직접 넣은 태그는 남깁니다.
  • 넣을 자리: 지금 캐릭터를 바꾸거나 새 캐릭터로 추가.
  • 신규 캐릭터(외형·의상 자료 없음)는 “이름만”만 켜져 있습니다.
  • ★은 여기와 그리드 양쪽에 있습니다. 도감에서 빼도 넣기에는 영향 없음.

  • 목록을 어디서 받을지: 19,316명 목록(압축 약 0.5 MB)을 앱에 넣을지, 처음 열 때 받을지. 썸네일 17,811장은 한 장 10–40 KB라 전부 받으면 수백 MB이므로 “본 것 + 도감”만 저장하는 안입니다. 라이선스가 적혀 있지 않아 개인 사용 전제입니다.
  • 신규 123명의 인기순 자리: 게시물 수 자료가 있으면 그 순서로 섞고, 없으면 시리즈 끝에 둘지.
  • 넣을 때 바꿀 범위: “+외형” 이후 다른 캐릭터로 바꾸면, 전에 넣은 외형 태그를 앱이 기억해 지우는 안입니다. 직접 고친 태그와 겹칠 때 어떻게 할지.
  • 누르기 = 바로 넣기?: 지금 도감은 누르면 바로 들어갑니다. A는 패널을 한 번 거칩니다. “패널 없이 바로 넣기” 설정을 둘지.
  • 랜덤에서 한 명만 빼기가 필요한지.
  • ＋(새 캐릭터)를 눌렀을 때 찾기 시트를 바로 열지.
