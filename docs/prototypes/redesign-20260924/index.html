NAI V5 Studio 디자인 콘셉트 · 2026-09-24

Galaxy Tab S11 세로 800×1280 기준 정적 목업. 이미지는 CSS 그라데이션, 프롬프트·개수는 가상의 값입니다. 노란 번호 메모는 설명용이며 UI가 아닙니다. 콘셉트 파일에 #화면을 붙이면 해당 화면을 볼 수 있습니다. 자세한 감사표와 근거는 README.md.

현재 0.5.2에서 본 것 (빌드된 dist, 이미지 없는 상태)

  1. 이미지 무대는 최대 43dvh. 832×1216 이미지가 약 376×550, 화면 면적의 약 20%.
  2. 화면 아래 절반이 같은 무게의 알약 버튼 3줄 (마무리, Seed·Prompt·Upscale·저장, 태그사전·해상도·steps·CFG·불러오기). 해상도·steps·CFG 세 버튼은 모두 같은 설정 시트를 연다.
  3. Anlas와 사용 한도가 따로 있고, “이번 생성이 무료인가”는 생성 버튼 안 작은 글씨.
  4. ARTIST / CHARACTER PROMPTS / OTHER / GENERATE / Settings 영문, 안내·토스트는 한국어.
  5. 🎲, Anlas 알약, 이미지 동작·빠른 설정 버튼은 40px로 44px 목표보다 작다.

B2태그 작업대 (B 다듬기, 사용자 피드백 반영)

이미지는 작은 썸네일 (누르면 전체 화면), 태그 편집이 화면 대부분. “달라진 점”은 조용한 한 줄, 2×2 동작 격자는 전체 화면 보기로 이동. 두 배치 비교.

B2-1 위쪽 띠

  • 편집기가 화면 전체 폭: 한 줄에 태그가 가장 많이 들어가 스크롤이 적다.
  • 섹션 탭 4개 (품질·제외 합침).

B2-2 왼쪽 열

  • 세로 탭 5개가 키보드가 떠도 그대로 보여 섹션 이동이 1탭.
  • 편집기 폭이 좁아 (588px) 태그 줄바꿈이 더 많다.

추천

  • B2-1. 태그 편집이 주인공이라면 전체 폭 편집기가 가장 큰 이득. 섹션 이동이 잦으면 B2-2.

A캔버스 우선

이미지가 화면을 채우고, 오른쪽 레일에 세션과 저장, 아래 독에 프롬프트 요약과 생성.

생성 · concept-a.html#generate 프롬프트 시트 · #prompt 전체 보기 + 정보 · #viewer 생성 설정 시트 · #settings

장점

  • 이미지 면적 약 3.2배. 결과를 보는 앱이라는 인상이 가장 강하다.
  • 저장·생성이 엄지 자리. 메인 화면 버튼 수가 가장 적다.
  • 현재 구조(카드 → 편집)를 시트로 옮기는 것이라 기능 손실이 없다.

비용

  • 프롬프트 전문은 한 번 밀어 올려야 보인다.
  • 키보드와 반 높이 시트의 조합은 기기에서 확인 필요.

B프롬프트 작업대

메인 화면에서 태그 칩을 바로 고치고, 사전은 키보드 자리의 도크. 직전 결과와 달라진 점 표시.

작업대 · concept-b.html#generate 키보드 편집 · #prompt 사전 도크 · #dictionary 앱 설정 · #settings

장점

  • 화면 전환이 가장 적다. 태그를 넣고 빼며 반복 수정하는 흐름에 최적.
  • “달라진 점”으로 어떤 태그가 효과였는지 보인다.

비용

  • 이미지는 지금과 비슷한 크기 (약 1.1배). 이미지 주인공 목표는 약하다.
  • 사전 도크는 지금의 iframe 사전을 다시 배치해야 한다.

C세션 롤 (연속 생성)

같은 프롬프트를 N번 차례로 생성하고, 도는 동안 ★ 보관, 끝나면 보관한 것만 저장.

연속 생성 중 · concept-c.html#generate 세션 검토 · #review 반복 설정 시트 · #prompt 비용 보호 설정 · #settings

장점

  • 랜덤 캐릭터(🎲)와 잘 맞는다. 생성 버튼을 반복해서 누를 필요가 없다.
  • 보관/저장 분리로 세션이 비워지기 전에 고르는 흐름이 생긴다.

비용

  • 새 동작: 요청 반복, 비용 보호, 화면 켜둠. 한도 소모 규칙은 아직 모른다.
  • 잘못 만들면 Anlas를 쓰게 되므로 가장 위험하다.
추천: A를 기본 방향으로. 먼저 저위험 정리부터 (무대 높이, 44px 터치 영역, 상태 알약 하나, 한국어 라벨, 생성 설정/앱 설정 분리). 그다음 A의 오른쪽 레일과 반 높이 프롬프트 시트. 시트 안의 편집은 B의 섹션 탭과 “키보드 위 한 줄 도구”를 빌린다. C의 반복 생성은 비용 보호가 확인된 뒤 A의 독에 “반복” 옵션으로만 더한다.
