0현재 기본 화면

버튼이 “무엇을 바꾸는지”가 아니라 “빈 자리가 있던 곳”에 놓여 있습니다. 그래서 같은 대상을 바꾸는 버튼이 흩어지고, 다른 대상을 바꾸는 버튼이 한 칸에 모여 있습니다.

  1. 이미지 옆 칸에 생성 값, 프롬프트 도구, 탭 메뉴, 이미지 저장이 섞여 있습니다.
  2. 더 보기(Prombot, 전체 복사, 텍스트로 편집, 불러오기, 캐릭터 설정, 전체 지우기)는 모두 지금 탭을 대상으로 하는데 보드가 아니라 이미지 옆에 있습니다. 이미지 파일 불러오기는 탭 하나가 아니라 프롬프트·설정 전체를 바꾸는데도 탭 메뉴 안에 있습니다.
  3. ‘설정’이 네 군데입니다. 캐릭터 줄의 설정은 랜덤 바로 옆이라 랜덤 설정처럼 보이지만, 실제로는 더 보기 → 캐릭터 설정과 같은 캐릭터 설정 시트를 엽니다. 이 시트 안에 캐릭터 프롬프트를 고치는 두 번째 입력칸이 있습니다(0c).
  4. 이미지 동작 중 저장만 메인에 있고, 마무리 켜기·Seed 고정·업스케일·프롬프트 복사·이 설정 불러오기·마무리 조절은 크게 보기 안에만 있습니다. 메인의 저장이 마무리를 적용하는지는 크게 보기에서만 바꿀 수 있습니다.
  5. 되돌리기/다시 실행은 보드 편집을 되돌리는데 생성 버튼 옆에 있습니다.
  6. 보드 아래쪽 절반이 비어 있고, 도구는 위쪽 칸에 몰려 있습니다.
  7. 오른쪽 위 눈·톱니 아이콘에 이름이 없습니다.
  8. (추가 발견) 같은 도구의 자리가 화면 상태마다 바뀝니다. 기본 화면에서는 이미지 옆 칸, 핸들로 편집 영역을 넓히면 생성 위 한 줄(생성 설정 아이콘·태그사전·번역·⋯·저장), 입력 중에는 키보드 위 줄입니다.
  9. (추가 발견) 캐릭터 탭에서 태그사전을 누르면 태그사전이 아니라 캐릭터 도감이 열립니다. 이름은 같은데 열리는 화면이 다릅니다.

2. 정리 방향 (같은 버튼, 다른 배치)

세 안 모두 공통으로 적용하는 것:

  • ‘설정’은 뜻마다 하나씩만 둡니다. 생성 설정(해상도·Steps·CFG 등, 생성 버튼 옆), 앱 설정(연결·저장 형식·번역·백업, 오른쪽 위 글자 버튼), 캐릭터 관리(위치·사용·삭제, 캐릭터 줄에만).
  • 랜덤은 켜기/끄기 버튼 하나이고, 랜덤 명단은 지금처럼 Prombot 북마크에서 가져옵니다. 따로 ‘랜덤 설정’ 화면은 없으므로, 랜덤 옆에 ‘설정’ 글자를 두지 않습니다.
  • 캐릭터 탭 보드 위에 [캐릭터 태그 | 이 캐릭터 제외] 전환을 둡니다. 품질·제외 탭의 [품질 | 제외] 전환과 같은 방식이고, 캐릭터 제외도 같은 태그 보드에서 고칩니다.
  • 캐릭터 탭에서는 사전 버튼 이름을 캐릭터 도감으로 바꿔, 열리는 화면과 이름을 맞춥니다.
  • 오른쪽 위 아이콘에 글자를 붙입니다(가리기, 앱 설정).

A메뉴 두 개: 이미지 메뉴 / 탭 메뉴

‘더 보기’가 두 개 있어서 헷갈리던 것을 이름과 자리로 나눕니다. 이미지 메뉴는 이미지 동작 옆에서, ○○ 메뉴(작가 메뉴·캐릭터 메뉴·장면 메뉴·품질 메뉴·제외 메뉴)는 보드 도구줄 끝에서 열립니다.

  • 이미지 파일 불러오기는 탭 메뉴에서 이미지 메뉴로 옮깁니다. 프롬프트·설정 전체를 바꾸는 동작이라 탭 메뉴에 있으면 “이 탭만 바뀌나?” 하고 헷갈리기 때문입니다.
  • 탭 메뉴에서 캐릭터 설정을 뺍니다. 캐릭터 줄의 캐릭터 관리 한 곳에만 둡니다.
  • 크게 보기 화면의 ⋯도 같은 이미지 메뉴를 엽니다. 크게 보기 아래 버튼(저장·마무리·Seed·업스케일)은 메인 이미지 구역과 같은 순서로 맞춥니다.

3. 추천: A (대상별 3구역)

A를 추천합니다. 이유:
  • “이 버튼은 무엇을 바꾸나”만 알면 자리가 정해집니다. 이미지를 바꾸면 이미지 옆, 태그를 바꾸면 보드 아래, 생성 값이면 생성 옆입니다. 지금 헷갈리는 원인(1, 2, 4, 5)이 모두 이 규칙 하나로 풀립니다.
  • 입력 중에도 자리가 같습니다. 보드 도구줄이 키보드 위로 같은 순서로 올라오므로(0b와 거의 같은 줄), B·C처럼 기본 화면과 입력 중의 모양이 달라지지 않습니다.
  • 이미지 크기와 보드 크기가 지금과 거의 같습니다. 빈 공간이던 이미지 옆 칸을 이미지 동작으로 채울 뿐이라 화면 전체가 새로 바뀌는 느낌이 적고, 적응이 쉽습니다.
  • 자주 쓰는 이미지 동작(마무리, Seed, 업스케일)이 크게 보기에 들어가지 않고 한 번에 눌립니다.
  • 생성은 지금처럼 맨 아래에서 가장 큰 버튼입니다. 되돌리기가 빠진 자리를 생성 설정이 채워서 생성 버튼 크기는 거의 같습니다.

B는 태그를 가장 많이 보고 싶을 때의 대안입니다. C는 한 줄에 모두 모이는 장점보다 좁아진 보드와 입력 중 모양 변화의 손해가 더 큽니다.
